## SECTION 3: PROJECT STRUCTURE

Create a new folder:

desktop_agent/

Inside it, create:

* vision.py        → context extraction (OCR-ready placeholder)

* README.md        → setup + usage instructions

## SECTION 4: SAFETY LAYER (MANDATORY)

This is the most important component.

Implement:

1. SAFE MODE (enabled by default)
2. Action allowlist (only safe actions allowed)
3. Rate limiting (delay between actions)
4. Emergency stop mechanism (keyboard interrupt or flag)
5. Logging of every action
6. Block dangerous operations (file deletion, system commands)

The system must NEVER perform destructive actions automatically.

## SECTION 8: CONTROLLER (CORE LOOP)

Implement loop:

1. Capture screen
2. Analyze context
3. Decide action (simple rule-based placeholder)
4. Validate via safety layer
5. Execute action
6. Wait (rate limit)
7. Repeat

DO NOT use infinite uncontrolled loops — include safe exit.
