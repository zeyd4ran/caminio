CORE LOOP LOGIC:

Implement an autonomous loop:

- input: goal string
- initialize memory
- repeat until:
    - goal is complete OR
    - maxSteps reached (default 25)

Each iteration:
1. Read system observation
2. Send prompt to Ollama with:
   - goal
   - memory
   - last result
3. Parse JSON response
4. Validate against tool registry
5. Execute tool
6. Store result in memory
7. Continue

Must include:
- loop detection prevention
- failure retry limit (max 3 retries per action)
- timeout per step
